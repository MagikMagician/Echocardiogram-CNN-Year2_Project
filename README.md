# Echocardiogram-CNN-Year2_Project

Coursework project developed as a reproducibility study of CNN-based Echocardiogram classification.

## Setup Instructions

### Windows

```bash
setup.bat
```

### Mac/Linux

```bash
chmod +x setup.sh
./setup.sh
```

The setup script will:

- Create a virtual environment
- Install all required dependencies
- Prepare the environment for development

### Activating the Environment

**Windows:**

```bash
venv\Scripts\activate
```

**Mac/Linux:**

```bash
source venv/bin/activate
```
